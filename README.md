# 🚀 NPIC Engineering Portfolio

Welcome to my personal engineering portfolio repository! This web application serves as a centralized platform to showcase my academic and professional projects.

## 🛠 Technologies & Skills
* **Microcontrollers:** STM32, ESP32, Arduino
* **Automation:** Siemens PLC (TIA Portal), SCARA Robotics
* **IoT Protocols:** MQTT, Node-RED
* **Hardware Design:** KiCad (PCB Layout)
* **Programming:** C/C++, HTML, CSS, JavaScript

## 📂 Features
* **Modern UI:** Built with Glassmorphism and smooth scroll animations.
* **Project Repository:** Downloadable schematics, source codes, and documentation.
* **Admin Dashboard:** A dedicated management panel for adding/removing projects.
